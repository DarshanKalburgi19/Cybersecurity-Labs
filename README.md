## 🛠️ Methodology & Tools
In these labs, I utilize a systematic approach to security testing:
1.  **Reconnaissance**: Analyzing application behavior and mapping endpoints.
2.  **Vulnerability Identification**: Using manual Interception (Burp Suite) to find logic flaws.
3.  **Exploitation**: Crafting Proof-of-Concept (PoC) attacks to verify impact.
4.  **Remediation**: Providing actionable developer-level fixes.

**Tools Used:**
* **Proxy**: Burp Suite Professional
* **Automation**: Python (Requests), Bash
* **Scanning**: Nmap, GoBuster
* **Exploitation**: Metasploit, SQLmap
